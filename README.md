# Technical Support Ticket Analysis Dashboard

![Dashboard Preview](Walk%20Through/Screenshots/Dashboard%20Overview.png)


An interactive Power BI dashboard designed to analyze technical support ticket performance, SLA compliance, ticket resolution efficiency, and support request trends.

---

## Project Overview

This dashboard helps support teams monitor ticket volumes, identify common issue categories, evaluate SLA performance, and improve operational efficiency through interactive visualizations.

The project consists of two report pages:

- Ticket Performance Dashboard
- Support Case Explorer

---

## Business Problem

Technical support teams often struggle to monitor increasing ticket volumes, track SLA compliance, and identify recurring customer issues.

This dashboard provides actionable insights into:

- Ticket trends over time
- Resolution efficiency
- SLA performance
- Product-wise ticket distribution
- Support request categories
- Ticket priorities
- Detailed ticket-level exploration

---

## Dashboard Features

### Page 1 — Ticket Performance Dashboard

- Total Tickets KPI
- Monthly Ticket Trend

- Product Group Analysis

- Most Common Support Requests
- Ticket Type Breakdown

### Page 2 — Support Case Explorer

- Detailed ticket records
